# 좁은 화면의 조작 방식

화면이 좁아 버튼을 다 둘 수 없을 때 쓰는 도구다.

| 환경 | 기본(보이는 경로) | 지름길(숨긴 경로) |
|---|---|---|
| 휴대폰 | ⋯ 더보기 → 하단 시트, 하단 도구 막대, 접기/펼치기 | 길게 누르기 → 같은 하단 시트, 세 번 누르기, 목록 줄 밀기(되돌리기 제공) |
| 데스크톱 | 클릭, 마우스를 올리면 나타나는 도구, ⋯ 메뉴 | 우클릭 → 같은 메뉴, 세 번 클릭, 키보드 단축키(메뉴 키·Shift+F10 포함), 명령 팔레트(⌘K) |

## 원칙: 숨긴 조작은 지름길이다
같은 기능을 **보이는 경로**(⋯ 버튼, 메뉴, 하단 시트)와 **키보드**로도 할 수 있어야 한다. 그래야 스크린리더·키보드·운동 장애 사용자와 숨긴 조작을 모르는 사용자가 쓸 수 있다.
- 근거 기준: WCAG 2.1.1 키보드, 2.5.1 포인터 제스처, 2.5.7 끌기 동작, 4.1.2 이름·역할·값
- 표시: 숨긴 조작이 있는 요소에 `data-gesture="longpress|tripletap|contextmenu|swipe"`를 붙이고, 대체 요소를 `data-gesture-alt="<selector>"`로 가리킨다. 측정 스크립트는 대체 요소가 보이는지 확인한다.

## 길게 누르기
- 누르는 시간은 기본 500ms 안팎으로 두되 조정할 수 있다.
- 손가락이 조금이라도 움직이면 취소해 스크롤과 충돌하지 않게 한다.
- 손을 떼는 순간 실행하고, 밖으로 끌어내면 취소한다(2.5.2 포인터 취소).
- 진입하면 시각 피드백을 준다. 지원 기기에서는 짧은 진동(`navigator.vibrate`)도 준다.
- 텍스트 선택이나 iOS 기본 메뉴와 겹치는 곳은 `-webkit-touch-callout: none`과 `user-select: none`으로 정리한다. 단, 읽기 본문의 글자 선택은 막지 않는다.

## 세 번 누르기·세 번 클릭
유용한 경우에는 쓴다. 예: 읽기 화면에서 문단 전체 선택, 숙련자용 빠른 실행, 숨긴 관리자 전환

쓸 때 지킬 조건은 다음과 같다.
- 같은 결과를 내는 보이는 경로나 키보드 경로가 있다.
- 한 번 누르기의 동작을 지연시키지 않는다. 처음 한두 번의 누름이 해롭지 않은 동작이어야 한다.
- 시스템 동작과 겹치는 곳을 피한다. 예: Android의 세 번 탭 확대(손쉬운 사용), 브라우저의 세 번 클릭 문단 선택
- 처음 쓸 때 안내 문구나 툴팁으로 알려 준다.

## 우클릭과 마우스를 올리면 나타나는 도구
- 우클릭 메뉴는 ⋯ 버튼 메뉴와 같은 항목, 같은 순서로 둔다.
- 마우스를 올리면 나타나는 도구·툴팁(1.4.13)
  - Esc로 닫을 수 있다.
  - 마우스를 그 위로 옮겨도 사라지지 않는다.
  - 키보드 초점으로도 나타난다.
- 메뉴를 닫으면 초점을 연 버튼으로 되돌린다.

## 함께 쓰면 좋은 방식
- **⋯ 더보기 메뉴와 하단 시트**: 가장 찾기 쉽고, 스크린리더로도 쓸 수 있다.
- **점진적 공개**: 자주 쓰는 것만 보여 주고 나머지는 '더보기'로 넣는다.
- **가로로 넘기는 탭·칩 줄**: 끝을 흐리게 처리해 더 있다는 것을 보여 준다([scrolling.md](scrolling.md)).
- **단축키**: 툴팁에 함께 적는다(예: "보관 (B)").
- **목록 줄 밀기**: 실행 뒤 되돌리기 알림을 띄운다.
