# 줄바꿈 (작은 화면, 한국어)

## 기준
- **한 줄이어야 하는 것**: 섹션명, 메뉴명, 항목명, 버튼, 탭, 칩, 설정 이름, 표 머리글. 320px·375px·데스크톱과 글자 125%에서 확인한다.
- **여러 줄을 허용하는 것**: 설명, 본문, 영상 제목 같은 콘텐츠. 다만 아래 둘은 지킨다.
  - 단어 중간에서 끊기지 않는다. 한국어는 어절(띄어쓰기 단위) 안에서 끊기면 안 된다. 예: "저장합 / 니다", "영상 / 을"(조사 앞 끊김)
  - 끝 줄에 한 글자나 짧은 한 단어만 남지 않게 한다(경고 수준).
- URL, 이메일, 코드, 긴 영문 식별자는 예외다. 대신 화면 밖으로 넘치지 않게 한다.
- **확대·긴 번역문 예외**: 한 줄 규칙은 320·375px 기본 크기에 적용한다. 200% 확대나 긴 번역문(독일어·프랑스어 등)에서 축약만으로 맞지 않으면 줄바꿈이나 반응형 대체(아이콘만 남기기, ⋯ 메뉴, 세로 배치)를 허용한다. 이때도 잘림·가로 스크롤은 금지다(WCAG 1.4.4, 1.4.10).

## 고치는 법 (순서대로 시도)
1. **문구를 줄인다.** 이름이 두 줄이면 대부분 이름이 길다. 예: "구독 채널 관리하기" → "채널 관리"
2. **한국어 줄바꿈 규칙을 켠다.**
   ```css
   :root { word-break: keep-all; overflow-wrap: break-word; }  /* 어절 단위로 줄바꿈 */
   .url, code { overflow-wrap: anywhere; word-break: normal; } /* 긴 문자열만 아무 곳에서나 */
   h1, h2, h3 { text-wrap: balance; }   /* 제목 줄 길이 균형 */
   p, .description { text-wrap: pretty; } /* 끝 줄 외톨이 방지 */
   ```
3. **짧은 라벨은 한 줄로 고정한다.** `white-space: nowrap`과 `min-width: 0`을 쓰고, 칸이 모자라면 격자(열 수)나 문구를 고친다. 말줄임(`text-overflow: ellipsis`)은 사용자가 만든 이름(폴더명, 채널명)에만 쓴다. 그때 `title`이나 툴팁으로 전체 이름을 보여 준다.
4. **배치를 바꾼다.** 이름과 버튼이 한 줄에 안 들어가면 버튼을 아이콘만 남기거나(접근성 이름은 유지), ⋯ 메뉴로 보내거나, 이름 아래 줄로 내린다.

## 하지 말 것
- `&nbsp;`나 `<br>`로 특정 폭에만 맞추기. 다른 폭과 다른 언어에서 더 나빠진다.
- 글자 크기를 줄여 억지로 한 줄에 넣기. 프로젝트 최소 크기를 지킨다(예: 보조 설명 13px, 입력 16px).
- 긴 번역문(영어·독일어 등)을 확인하지 않기. 다국어 화면이면 가장 긴 언어로도 잰다.
