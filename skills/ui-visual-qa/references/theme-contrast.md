# 밝음·어두움 테마에서 보이는지

## 기준 (WCAG 1.4.3, 1.4.11)
- 본문 글자는 4.5:1 이상이다.
- 큰 글자(24px 이상, 또는 18.66px 이상 굵게)는 3:1 이상이다.
- 의미 있는 아이콘, 입력 경계, 버튼 경계(배경으로 구분하지 않을 때), 초점 링, 선택 표시는 3:1 이상이다.
- 사용할 수 없는 버튼(disabled)은 대비 기준에서 빠진다. 다만 '안 보임'이 아니라 '흐림'이어야 하고, 쓸 수 없는 이유를 보여 준다.
- **두 테마 모두** 잰다. 한쪽에서 고친 색이 다른 쪽에서 사라지는 경우가 가장 흔하다.

## 재는 법
- 앱 자체의 테마 전환 방식(`data-theme`, 클래스, 설정 저장값)과 `prefers-color-scheme`을 **둘 다** 바꾼다. 하나만 바꾸면 반쪽만 바뀐 화면을 재게 된다.
- 계산값이 `oklch()`나 `color()`여도 스크립트는 캔버스로 sRGB로 바꿔 계산한다.
- 배경이 그림이나 그라데이션이면 자동 계산을 할 수 없다(`warn: 배경 확인 불가`). 스크린샷에서 가장 어두운 곳과 가장 밝은 곳을 눈으로 확인한다.
- 강제 색상 모드(`forced-colors: active`, Windows 고대비)에서는 아이콘이 `currentColor`를 따르는지, 경계가 사라지지 않는지 본다.

## 고치는 법
- 개별 요소에 색을 박지 않고 **테마 토큰**을 고친다. 예: `--text-secondary`, `--icon-muted`, `--border-control`
- 흐린 글자나 아이콘에 `opacity`를 쓰면 두 테마에서 대비가 다르게 무너진다. 토큰 색을 따로 정한다.
- 아이콘은 `stroke="currentColor"`로 두고, 색은 부모 글자색 토큰이 정한다.
