# 구현 수용 테스트

## RED 기준선에서 확인된 실패

스킬 없이 같은 문제를 검토했을 때 다음 잘못된 해법이 반복됐다.

- `high/low ± ATR × 고정 계수`: 작은 봉에서 후속 간격이 붕괴하거나 큰 호가 종목에서 과도하게 멀어졌다.
- `label.style_none`: 좌표는 wick 밖이어도 고정 픽셀 텍스트가 앵커 중심으로 펼쳐져 wick에 침범했다.
- 방향별 합성 라벨 또는 `+N`: 같은 봉 충돌은 줄였지만 사용자가 지정한 각 신호를 직접 볼 수 없었다.
- 다이버전스 X 무제한 이동: 원 신호 봉/피벗의 의미가 훼손됐다.
- 고정 신호 번호를 슬롯으로 사용: 비활성 신호가 빈 간격을 만들었다.
- 모든 표시 선 회피: 관계없는 먼 선이 스택 전체를 화면 밖으로 밀었다.

## 자동 계약

대상 프로젝트의 기존 검증 방식에 맞춰 아래 항목을 실패 테스트로 먼저 추가한다.

### 좌표와 wick

- 상단 첫 앵커 `> high`, 하단 첫 앵커 `< low`.
- ATR이 `na` 또는 0이어도 최소 tick fallback으로 유한한 좌표 생성.
- 첫 간격과 후속 간격의 스케일 분리.
- 모든 가격 인접 렌더러에서 `label.style_none`과 center 스타일 부재.
- 위쪽은 `style_label_down`, 아래쪽은 `style_label_up`.

### 큐와 정보 보존

- 활성 신호 ID multiset과 배치된 신호 ID multiset 동일.
- 방향별 활성 슬롯은 빈 칸 없이 `0..n-1`.
- 같은 활성 집합이면 조건 평가 순서와 무관하게 결과 순서 동일.
- `+N`, overflow suppression, 3개 제한, tooltip-only 대체 부재.
- 첫 항목은 완성된 앵커, 이후 항목은 `previous outer/current inner` 쌍별 거리 사용. 기존 단일 extent 엔진은 보수 계수의 화면 검증 필요.

### 시각 점유

- 텍스트/아이콘과 말풍선의 기본 extent가 다름.
- size 단계와 줄 수가 extent에 반영됨.
- 여러 줄 MACD/GC 배지가 충분한 세로 extent를 예약함.
- 긴 한 줄 다이버전스는 세로 extent를 부풀리지 않고 이웃 회피용 width class를 가짐.
- 도지·작은 봉 표본에서도 RSI 숫자와 1B/2B 말풍선 사이 최소 예약 간격 유지.

### 기준선과 다이버전스

- 소스의 활성 조건을 만족하고 값이 `na`가 아닌 관련 선만 수집하고 회피 창은 첫 앵커 주변의 작은 범위로 제한.
- 모습 탭의 수동 plot 숨김 상태를 Pine에서 읽을 수 없다는 한계 명시.
- 먼 선을 추가해도 첫 앵커가 로컬 상한 밖으로 이동하지 않음.
- 현재 봉 스택의 최외곽 좌표를 방향별 레지스트리에 저장.
- 피벗 신호는 `x-1, x, x+1` 레지스트리의 가장 바깥 꼬리를 검사하되 원래 X를 유지.
- 늦게 확정된 피벗은 reflow가 없으면 기존 tail 바깥에 배치.
- 레지스트리 보존 기간이 최대 피벗 확정 지연과 이웃 검사를 덮음.
- 레지스트리 길이에 명시적 상한 존재.

### 회귀와 자원

- 기존 `alertcondition()`과 모든 동적 `alert()` 선언 해시 불변. 동적 알림의 메시지·`freq`·실행 게이트·호출 위치·횟수를 포함하고, 가능한 프로젝트는 대표 데이터의 발생 봉·횟수 trace도 불변.
- 실제 소스에 존재하는 모든 `plot*`, `fill`, `hline`, `bgcolor`, `barcolor` 비대상 스타일 선언 해시 불변.
- 변경 전후 plot count 동일, `<= 64`, 프로젝트가 정한 안전 여유 유지.
- label/line 최대 수와 보존 정책 명시.
- 제거된 상세 문자열 큐·조합별 중복 코드가 다시 생기지 않음.

## 결정적 표본

최소 다음 조합을 수치 시뮬레이션한다.

1. 신호 0개, 1개, 모든 종류 동시 발생.
2. RSI 숫자 + 1B + 2B + MTF BB + MACD 아이콘 같은 방향.
3. 상·하단 최대 신호 동시 발생.
4. ATR 초기 `na`, ATR 0, 1-tick, 큰 호가 단위.
5. 도지, 긴 위/아래 wick, 장대봉, 갭.
6. 같은 피벗 X와 `x±1`에 기존 넓은 말풍선이 있는 다이버전스.
7. 최대 밀집 신호가 여러 봉 연속 발생하는 객체 한도 스트레스.

테스트 하네스가 없으면 정적 선언 검사와 순수 좌표 시뮬레이터를 먼저 추가한다. 실제 TradingView 서버에 접근할 수 없는 상태는 `로컬 검증 완료, 서버·화면 검증 대기`이며 완전 합격이 아니다.

## 실제 TradingView 화면 행렬

자동 테스트는 픽셀 bbox를 증명하지 못한다. 정확한 소스를 새 Untitled script에 넣어 서버 컴파일한 뒤 다음을 확인한다.

| 축/화면 | 표본 |
|---|---|
| 가격축 | Auto, 수직 확대, 수직 축소, 위/아래 드래그 |
| 시간축 | 넓은 봉, 보통, 조밀한 축소 |
| 캔들 | 도지, 긴 wick, 장대봉, 갭 |
| 밀도 | 단독, 2개, 최대 동시 신호, 연속 밀집 |
| 기준 | BB 상·하단, MA/VWAP 교차, 다이버전스 피벗 |

합격 기준:

- 신호가 자기 wick 안으로 들어가지 않는다.
- 같은 봉 신호 순서가 고정되고 서로 덮지 않는다.
- 첫 신호가 불필요하게 멀지 않다.
- 캔들·이평선·밴드·신호가 함께 움직인다.
- 극단적 가로 축소에서 발생하는 이웃 봉 픽셀 충돌은 Pine 한계로 별도 기록한다.
