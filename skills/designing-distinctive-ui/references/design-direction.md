# Design Direction

Use this procedure for a new surface, a full redesign, or a screen with no
coherent identity. It turns product truth into a design thesis before a style
trend becomes the default.

## Design Read

Establish:

```text
제품 소재 / 핵심 사용자 / 이 화면의 단일 목적 / 실제 증거 / 금지된 추정
```

Product material means the real nouns, artifacts, decisions, and rhythms of the
work. An API product may expose endpoints, request/response pairs, authentication,
latency, and code scanning. A finance tool may expose periods, comparisons,
confidence, and exceptions. Translate those structures into hierarchy and
interaction; do not decorate them with a category cliché.

When facts are missing:

- if direction is delegated, state a safe working hypothesis and proceed without
  inventing claims;
- otherwise ask one question only when different answers would materially change
  the visual world or information architecture;
- use labeled examples or placeholders for unknown product facts.

## Fact Boundary

A working hypothesis may define the audience, page job, hierarchy, and visual
system. It may not invent what the product supports or promises. Treat
capabilities, endpoints, authentication, integrations, pricing, availability,
customer evidence, performance, compliance, onboarding time, and CTA
destinations as unknown until the repository or user supplies evidence.

Do not turn a plausible information architecture into a factual feature list.
For an unknown section or action, use a clearly labeled structural example such
as `예시 요청`, a neutral destination such as `문서 보기` only when that
destination exists, or omit it. Before handoff, replace or remove placeholders;
never ship them as product truth.

## Direction Sheet

Before implementation, record:

```text
디자인 명제:
정보 흐름:
타이포 역할: display / body / utility·code
컬러 역할: background / surface / text / muted / accent / status
레이아웃 원리:
단 하나의 시그니처:
모션의 목적:
안티 레퍼런스:
```

Typography roles must explain hierarchy, not merely name fashionable fonts.
Choose one signature grounded in the subject and spend visual boldness there.
Supporting elements should be quiet enough to clarify it.

## Anti-Template Counterfactual

Before handing the direction to Impeccable, ask:

1. If the logo and accent color disappear, does the structure still reflect
   this product?
2. Could the same plan describe an unrelated product with nouns swapped?
3. Does the signature improve the single job or only advertise style?

Revise if the first answer is no or either later answer is yes. A user-requested
trend may remain, but it must receive a bounded, product-specific role rather
than become the whole identity.
