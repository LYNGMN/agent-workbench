# Pine 컴파일러 현장 기록

공식 문서에 없는 실제 관찰을 누적한다. 프로젝트 서사가 아니라 다른 Pine 작업에서 재검증할 수 있는 증거만 남긴다.

## 기록 규칙

각 항목에 날짜, Pine 버전, 이전/이후 파일, 정확한 서버 오류 수치, 한 가지 변경, 결과, 해석, 검증 상태를 적는다.

- `서버 확인`: TradingView 컴파일 결과가 있다.
- `로컬 확인`: 정적 검사만 통과했다.
- `미검증`: 다음 서버 컴파일이 필요하다.

한 사례에서 효과가 없었던 방법을 모든 코드에 일반화하지 않는다. 특히 문자열은 공식적으로 IL에 포함될 수 있지만, `input.*()` 메타데이터처럼 별도로 처리되는 위치가 있다.

## 2026-08-31 · 대형 Pine v6 지표 CE10117

### 공용 rolling cache로 중복 계산 제거 — 서버 확인

- 이전: V1.18.48, `101,288 / 100,256`
- 이후: V1.18.49, `100,302 / 100,256`
- 변경: 상태라인 전용 배열과 매 표시 bar의 재구축 loop를 제거하고 기존 rolling 구조 배열을 공유했다.
- 결과: 컴파일 토큰이 986개 감소했다. 매매 판정, 알림 31개, plot ledger 50개는 정적 비교로 보존했다.
- 해석: 출력에 연결된 중복 state와 반복 계산을 없애는 구조 변경은 실제 IL을 줄일 수 있다.

### input 도움말 문자열 길이 축약 — 서버 확인, 효과 없음

- 이전: V1.18.49, `100,302 / 100,256`
- 이후: V1.18.50, `100,302 / 100,256`
- 변경: `input.*()`의 tooltip constant strings를 소스 기준 1,690 bytes 줄였다.
- 결과: 서버의 컴파일 토큰 수가 정확히 같았다.
- 해석: 이 사례의 input tooltip 내용 길이는 관측 가능한 IL 감소를 만들지 않았다. 모든 constant string이 무효라는 뜻은 아니다.

### input tooltip 인자 제거 — 서버 확인, 효과 없음

- 이전: V1.18.50, `100,302 / 100,256`
- 이후: V1.18.51, `100,302 / 100,256`
- 변경: `input.*()`의 `tooltip=` 인자 38개를 제거했다.
- 결과: source lexical proxy는 152 감소했지만 서버 컴파일 토큰 수는 정확히 같았다. 실행 코드·입력값·플롯·알림 정적 비교는 통과했다.
- 해석: 이 사례에서는 input tooltip의 내용뿐 아니라 `tooltip=` 인자 자체를 없애도 관측 가능한 IL 감소가 없었다.

### 반복 모드 판정을 공유 입력값으로 통합 — 로컬 확인

- 이전: V1.18.51, `100,302 / 100,256`
- 이후: V1.18.52, 서버 결과 미확인
- 변경: `positionTrackingMode == "특정 시점부터 추적"` 판정 52개를 input-qualified bool 하나로 공유하고, 관련된 세 개의 무인자 helper도 공유 bool로 바꿨다.
- 로컬 결과: source lexical proxy가 135 감소했다. 입력 선언 수, 알림 31개, plot ledger 50개, Replay 진입·청산 함수가 정적 비교에서 보존됐다.
- 해석: `input active`와 신호·알림 실행 경로에 연결된 반복 판정이므로 tooltip 축약과 다른 구조 가설이다. 실제 IL 감소량과 CE10117 해소 여부는 TradingView 서버 컴파일 전까지 확정하지 않는다.

## 2026-08-31 · 아이콘과 상태라인 플롯 예산

- `plotshape()` 크기 4종을 롱·숏에 제공하면 컴파일 타임 `size` 제약 때문에 8개 호출이 필요하다.
- 아이콘을 `display=display.pane`으로 제한하면 상태라인 값 노출은 막을 수 있지만 각 호출의 plot count는 유지된다.
- 과거 캔들 hover에서 현재선 가격을 보이려면 상태값이 각 bar의 series로 존재해야 한다. 마지막 bar에서만 계산한 값은 과거 상태라인 조회를 충족하지 못한다.
- 위 항목은 기능 설계와 정적 검증에서 확인했다. 실제 플롯 총수는 TradingView 컴파일과 함께 확인한다.
