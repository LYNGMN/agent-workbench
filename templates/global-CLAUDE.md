# 전역 Claude 지침 (agent-workbench 틀)

이 파일은 agent-workbench가 깔아 주는 시작용 틀입니다(`~/.claude/CLAUDE.md`). Claude Code와 VS Code의 Claude 확장이 모든 프로젝트에서 읽습니다. 자기 방식에 맞게 고쳐 쓰세요. 프로젝트의 `CLAUDE.md`가 있으면 그쪽을 먼저 따릅니다.

## 언어

- 사용자에게 보이는 모든 글은 한국어로 쓴다. 답변, 진행 상황, 질문과 선택지, 최종 보고가 모두 포함된다.
- 영어로 된 도구 결과·오류·웹 문서를 읽은 직후에도, 중단 뒤 다시 시작할 때도 한국어로 쓴다.
- 코드, 커밋 메시지, 파일 경로, 명령어, 식별자는 원래 표기를 유지한다.

## 작업 원칙

- 프로젝트의 `CLAUDE.md`와 `AGENTS.md`(다른 AI 도구와 함께 따르는 공용 지침)를 따른다. 같은 주제에서 다르면 같은 폴더의 `CLAUDE.md`가 우선한다.
- 구현 전에 구조를 확인하고, 큰 변경은 계획을 먼저 보여 준다. 결과만 요청하면 설명을 줄인다.
- 민감 정보는 출력하지 않는다.
- UI를 만들거나 바꾼 뒤에는 보여 주기 전에 `ui-visual-qa`로 320·375px·데스크톱, 밝음·어두움을 숫자로 확인한다(가운데 정렬, 겹침, 두 테마에서 안 보이는 부분, 이름 한 줄, 화면 밖 메뉴, WCAG 2.2 AA).

## 선택적 스킬 실행

- 명확하고 단순한 요청은 기본 도구로 처리한다. 전문 절차가 필요한 단계에서는 `~/.agents/skills/skill-router/SKILL.md`를 읽고 담당 스킬 하나와 필수 의존성만 고른다. 추천은 최대 2개.
- `using-superpowers`의 "1%라도 해당하면 호출" 규칙은 적용하지 않는다(agent-workbench는 이 스킬을 기본으로 끈다).
- 묶음 스킬은 사람이 부를 때 `/gstack-browse`, `/superpowers-brainstorming`처럼 `<팩>-<이름>`이다. 모델이 부를 때는 원래 이름(`browse`, `brainstorming`)을 쓴다.
- 합의된 범위와 승인을 반복해서 묻지 않는다. 통과한 검사는 변경이나 새 실패가 없으면 다시 돌리지 않는다.
- 사용자가 답한 취향·방식 결정 가운데 다시 나올 만한 것은 메모리에 남기고, 다음에는 지난 결정대로 한 뒤 한 줄로 알린다.
- 로컬 개선 요청을 게시·배포·병합 요청으로 넓히지 않는다.
